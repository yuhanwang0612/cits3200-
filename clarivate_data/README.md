# Clarivate journal enrichment

This directory is generated by `enrich_clarivate.mjs` from
`cleaned_data/journals.csv` and the Web of Science Journals API.

- `journal_metrics.csv` / `journal_metrics.json`: one enrichment result per
  processed local journal. Only exact normalized ISSN/eISSN matches have
  `clarivate_match_status=matched`.
- `clarivate_review_queue.csv`: unmatched, ambiguous, title-only, API-error,
  and matched-with-warning records that need attention.
- `clarivate_unmatched.csv`: every record not automatically matched.
- `clarivate_quality.json`: coverage counts and the matching policy used.
- `cache/`: raw API response cache. It is intentionally excluded from Git.

The API key is read from `CLARIVATE_API_KEY` or a repository-local `.env`
file. The key is never written to output files or request URLs.
