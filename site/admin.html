Edit data

Pick a dataset, download it as Excel, edit the cells, then upload it back. There are 3 different data sets that can be downloaded; Journals, Pulbications and Staff (researcher) In order for an edit to take affect, ensure that you choose the correct data set, download the Excel sheet, edit and save your changes, and re-upload the sheet. Make sure that section 1. "Choose dataset" is set to the correct one when uploading the Excel sheet.

Note: Changes made to the Journal and Staff (researcher) datasets will affect the publications dataset, while the reverse is not true.

For publications, rows are matched on publication_id; leave that cell blank to add a new publication (it will need a valid researcher_id). Only the publication columns are saved — researcher_name, university, journal_name and issn are shown for context and ignored on upload.

Note: spreadsheet edits change the live database. A later full source refresh rebuilds that database from the pipeline outputs, so manual edits can be replaced; the refresh creates a database backup first.

Refresh source data

Run every available Group of Eight university scraper and rebuild the database from the new pipeline outputs.

Important: this can take a long time. The current website database stays in place while scraping runs. A backup is created first, and the live database is replaced only after every university and the database reload succeed.

If one source fails, the job stops and reports which source failed. The existing live database is left unchanged; see the job log for the source error.
