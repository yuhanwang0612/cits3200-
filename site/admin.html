Download every publication as an Excel sheet, edit the cells, then upload it back. Rows are matched on publication_id; leave that cell blank to add a new publication (it will need a valid researcher_id). Only the publication columns are saved — researcher_name, university, journal_name and issn are shown for context and ignored on upload.

Note: spreadsheet edits change the live database. A later full source refresh rebuilds that database from the pipeline outputs, so manual edits can be replaced; the refresh creates a database backup first.
